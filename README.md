# Portofolio Deni Putra Hariadi K

Website portofolio (satu file `index.html`), di-hosting gratis lewat GitHub Pages.

Memperbarui isi: buka website → dashboard (klik **Admin** di footer atau `Ctrl + Shift + A`) → ubah → tab *Publikasi & cadangan* → **Unduh index.html** → unggah ke repository ini menggantikan file lama.
